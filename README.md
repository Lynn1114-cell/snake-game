# 贪吃蛇游戏

一个用纯HTML、CSS和JavaScript制作的经典贪吃蛇游戏。

## 在线游戏

点击这里开始游戏：[开始游戏](https://你的GitHub用户名.github.io/snake-game/)

## 游戏特点

- 🎮 经典的贪吃蛇玩法
- 🎨 精美的渐变色界面
- 📱 支持移动端和PC端
- 💾 自动保存最高分
- ⏸️ 支持暂停功能

## 如何游玩

- 使用方向键控制蛇的移动
- 吃到红色食物增加分数
- 避免撞墙和撞到自己
- 按空格键暂停/继续游戏

## 本地运行

直接打开 `snake_game.html` 文件即可在浏览器中运行。

## 技术栈

- HTML5 Canvas
- 原生JavaScript
- CSS3动画

祝你玩得开心！🐍
